# Changelog

Здесь фиксируется каждое изменение: что сделано, **почему** и какие новые фичи появились.
Новые записи добавляются сверху. Формат: `Added` — новые фичи, `Changed` — изменения, `Removed` — удалено, `Fixed` — исправления (с причиной).

## [Unreleased] — 2026-10-09

### Added
- **YandexGPT** как текстовая модель (OpenAI-совместимый API Yandex AI Studio): переменные `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, настройки `YANDEX_BASE_URL`, `YANDEX_MODELS` (по умолчанию `yandexgpt-5.1`, затем `yandexgpt-lite`), `YANDEX_TIMEOUT`, `YANDEX_MAX_CONCURRENT`, `YANDEX_BREAKER_FAILS`, `YANDEX_BREAKER_PAUSE`, `YANDEX_DATA_LOGGING`. Причина: правки YandexGPT на русском признаны лучшими; сама модель без холодного старта (он был у хостинга).
- Профили **«🟡 Yandex (с fallback)»** (YandexGPT, при сбое цепочка «Авто» и Groq) и **«🟡 Yandex (only)»** (только Яндекс, без подмены) в `/model`.
- **Предохранитель** для Yandex: после 3 сбоев подряд модель пропускается на 120 с. Причина: иначе каждый запрос ждал бы таймаут перед откатом.
- Отказы YandexGPT от «чувствительных» тем (фильтр контента) распознаются и **не** считаются сбоем сервиса: текст уходит запасной модели.
- Команда **`/llmcheck`** (админ): пробный запрос каждому звену (Yandex, OpenRouter, Groq) с временем ответа плюс сверка всех моделей из настроек с живыми списками провайдеров.
- **Проверка моделей при старте**: фоновая сверка с `GET /models` у OpenRouter и Groq, предупреждения `⚠️ МОДЕЛЬ: …` в лог.
- Кэш «мёртвых» моделей: ответ 404 отключает модель на час. Причина: бесплатные модели снимают без предупреждения, и каждый запрос терял попытку на снятой модели.
- **`APP_LLM_PROFILE`** (по умолчанию `yandex`): правка текста для Android-приложения (`/api/dictate`, `/api/correct`) идёт по этому профилю независимо от `/model`. Распознавание речи осталось на Groq.
- `GROQ_VISION_MODELS`: запасная vision-модель Groq для OCR (`qwen/qwen3.6-27b`), если основная вернёт 404.

### Changed
- **В `/model` показываются только рабочие модели.** Профиль скрывается, если его модели нет у провайдера, она отвечала 404 или провайдер не настроен; причины перечислены под меню. Если список провайдера получить не удалось, ничего не скрывается. Выбранная, но недоступная модель помечается предупреждением, старые кнопки меню для недоступных моделей не срабатывают.
- Цепочки OpenRouter для «Как есть», «Красиво», субтитров и саммари: **Nemotron 3 Super → Nemotron 3 Ultra**. Vision (`/img2prompt`): Nemotron 3 Nano Omni → Inkling Small.
- В `/llmcheck` лимит пробного ответа 64 токена; пустой ответ рассуждающей модели помечается как «токены ушли на размышления», ошибка 429 — как временный лимит провайдера.
- README: добавлены разделы «Цепочка моделей и fallback» и «API для Android-приложения».

### Removed
- **`qwen/qwen3.8-27b:free`** и профиль «Qwen». Причина: OpenRouter отозвал бесплатный вариант 05.10.2026 (ответ 404 «This model is unavailable for free»).
- **`stealth/space-bunny-alpha`** и профиль «Space Bunny». Причина: stealth-модель снята.
- **Gemma 4 31B и 26B** (`google/gemma-4-*-it:free`) и их профили. Причина: бесплатный провайдер Google стабильно отвечал 429.

### Fixed
- **Профиль «Qwen» в `/model` давал ошибку 404.** Причина: см. выше, бесплатный Qwen отозван; цепочки, где он стоял первым (субтитры, саммари), тратили попытку на мёртвую модель при каждом запросе. Теперь модель удалена, а любая модель, ответившая 404, временно пропускается.
- **В репозиторий случайно попали `__pycache__/*.pyc`** (побочный след локальных тестов). Удалены из индекса, добавлен `.gitignore` (`__pycache__/`, `*.pyc`, `.env`).
